# Число словами → цифры

Программа на Python и tkinter переводит записанное по-русски число от 0 до 999 в цифры и проверяет, правильно ли оно записано. Учебная практика.

## Возможности

- Перевод числа из слов в цифры, регистр и лишние пробелы не важны.
- Проверка порядка слов. Если число записано с ошибкой, программа называет конкретное слово и причину.
- Вставка из буфера по Ctrl+V работает и в русской раскладке, есть вставка через правую кнопку мыши.
- Окно открывается по центру экрана, его размер можно менять.

| Ввод | Результат |
| --- | --- |
| `семьсот двадцать три` | 723 |
| `Сто` | 100 |
| `девятнадцать` | 19 |
| `сорок сто` | После десятков(сорок) не могут идти сотни(сто)! |
| `двадцать сорак` | Во 2 слове(сорак) ошибка! |
| `пять три` | После единиц(пять) не могут идти единицы(три)! |
| `ноль пять` | После нуля(ноль) не могут идти единицы(пять)! |

## Запуск

Нужен Python 3.8 или новее, только стандартная библиотека.

```bash
python number_words.py
```

## Управление

| Клавиша | Действие |
| --- | --- |
| `Enter` или кнопка «Перевести» | перевести число |
| `Ctrl+V` | вставить текст в поле ввода |
| правая кнопка мыши по полю | меню «Вставить» |
| `F1` | меню «О программе» и «Горячие клавиши» |

## Как устроено

1. Каждое слово относится к одной из категорий: ноль, единицы (один–девять), числа 10–19, десятки (двадцать–девяносто) или сотни (сто–девятьсот). Неизвестное слово сразу даёт ошибку с его номером.
2. Последовательность категорий проверяется по грамматике (в квадратных скобках — необязательная часть):

```text
число = ноль
      | сотни
      | [сотни] десятки [единицы]
      | [сотни] число_10_19
      | [сотни] единицы
```

3. Функция `parse()` не зависит от окна: она возвращает пару `(число, None)` или `(None, текст ошибки)`, а интерфейс только показывает результат.

Стандартная вставка Tkinter по Ctrl+V не срабатывает при русской раскладке: программа получает другой символ клавиши. Поэтому обработчик проверяет код физической клавиши V (86 в Windows), который от раскладки не зависит.
